# Native pattern to Effect core module

Look up the native pattern you are about to write, use the Effect API in the second column, and read its declaration through [core-index.md](core-index.md). [checklist.md](checklist.md) is the review that goes with this table. The third column names the check that reports the native pattern:

- `core/*` rules come from `lint/effect-core-plugin.mjs`, which the root `oxlint.config.ts` turns on as errors. They run in files that import `effect`.
- The camelCase names are `@effect/tsgo` language-service diagnostics, reported by `effect-tsgo tsc` in each package's `typecheck` and in `typecheck:root`. `diagnosticSeverity` in `tsconfig.base.json` sets their severity, and a package's `tsconfig.json` can override it. Those marked _advisory_ stay suggestions because they report most native calls.

Check the declaration before replacing a call. Several Effect versions differ from the native one: `Array.findFirst` returns `Option`, `String.indexOf` returns `Option<number>`, `Array.filterMap` takes a function returning `Result`, and Effect callbacks take `(value, index)` only.

## Numbers and strings

Read each export through [core-index.md](core-index.md): `rg -n '^\| (Number|Order|String) \| (clamp|max|min|kebabCase|camelCase|snakeCase|pascalCase|constantCase|capitalize|uncapitalize) \|' .agent_sources/effect/core-index.md`, then `sed -n '<Start>,<End>p' node_modules/effect/dist/<Module>.d.ts`.

| Native                                                                                                              | Effect                                                                                                                                                                                                | Check |
| ------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----- |
| `Math.min(high, Math.max(low, value))`, a hand-written `clamp`                                                      | `Number.clamp(value, { minimum: low, maximum: high })`; a non-number type, `Order.clamp(order)(value, { minimum, maximum })` (`DateTime`, `Duration`, `BigInt`, and `BigDecimal` also export `clamp`) |       |
| `Math.max(a, b)`, `Math.min(a, b)` on two numbers                                                                   | `Number.max(a, b)`, `Number.min(a, b)`; other types, `Order.max(order)(a, b)`, `Order.min(order)(a, b)`                                                                                               |       |
| `str.replace(/[A-Z]/g, ...).toLowerCase()` to build kebab-case, snake_case, camelCase, PascalCase, or CONSTANT_CASE | `String.kebabCase(s)`, `String.snakeCase`, `String.camelCase`, `String.pascalCase`, `String.constantCase`; check the declaration for how each splits words before replacing a regex                   |       |
| `s[0].toUpperCase() + s.slice(1)`                                                                                   | `String.capitalize(s)`, `String.uncapitalize(s)`                                                                                                                                                      |       |
| `s.toLowerCase()`, `s.toUpperCase()`                                                                                | `String.toLowerCase(s)`, `String.toUpperCase(s)`                                                                                                                                                      |       |
| `typeof x === "string"`, a hand-written `isRecord` | `Predicate.isString`, `Predicate.isNumber`, `Predicate.isBoolean`, `Predicate.isFunction`, `Predicate.isObject`, `Predicate.isReadonlyObject`, `Predicate.isUndefined`, `Predicate.isNotUndefined`, `Predicate.isNotNull`; compose with `Predicate.and`, `Predicate.or`, `Predicate.not` | `core/no-typeof-check` |
| `s.trim()`, `s.split(sep)`, `s.slice(a, b)`, `s.startsWith(p)`, `s.replace(a, b)`, `s.includes(t)` | `String.trim(s)`, `String.split(s, sep)` (dual; returns a `NonEmptyArray`), `String.slice(a, b)(s)`, `String.startsWith(p)(s)`, `String.replace(a, b)(s)`, `String.includes(t)(s)`; most `String` functions are data-last only, so curry them or `pipe` | `preferEffectString` |
| `s.slice(0, n)` | `String.takeLeft(s, n)`, `String.takeRight` | `preferEffectString` |
| `s.indexOf(t) === -1`, `s.search(re)` | `String.indexOf(t)(s)`, `String.search(s, re)` (dual): both return `Option<number>` | `preferEffectString` |
| `s === ""`, `s.length === 0`, `if (s)` | `String.isEmpty(s)`, `String.isNonEmpty(s)` | `core/no-length-check`, `strictBooleanExpressions` |

## Effects over many values

| Native                                                   | Effect                                                                                                                                    | Check                                    |
| -------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------- |
| `for (const x of xs) { yield* f(x) }` collecting results | `yield* Effect.forEach(xs, f)`; add `{ concurrency }` when the calls are independent, `{ discard: true }` when the results are not needed | `core/no-yield-in-loop`                  |
| A loop of `yield*` that keeps or finds elements          | `Effect.filter(xs, f)`, `Effect.findFirst(xs, f)` with an effectful predicate                                                             | `core/no-yield-in-loop`                  |
| `Effect.all(xs.map(f))`                                  | `Effect.forEach(xs, f)`                                                                                                                   | `allOfMapToForEach`                      |
| A loop that threads state through effects                | `Effect.reduce`                                                                                                                           | `core/no-yield-in-loop`                  |
| `Promise.all`, `new Promise`, `async` functions          | `Effect.forEach`, `Effect.callback`, `Effect.gen`                                                                                         | `newPromise`; `asyncFunction` (advisory) |
| `yield*` written as a call argument                      | Yield into a `const` first, or `Effect.flatMap`                                                                                           | `yieldInCallArgument`                    |

A `yield*` loop that must stop early or poll may stay a loop; put a `// loop: <reason>` comment on the line above it.

## Node scripts

A script under `scripts/` is a TypeScript Effect program that plain `node` runs (type stripping, so only erasable syntax). `NodeServices.layer` from `@effect/platform-node` provides `FileSystem`, `Path`, `ChildProcessSpawner`, `Stdio`, and `Terminal`. Worked examples in this repository: `scripts/land/land.ts` and `scripts/effect-api/`. Upstream: `node_modules/effect/ai-docs/src/60_child-process/`, `70_cli/`, and `01_effect/06_running/`. Each API that `@effect/language-service` marks unstable (`FileSystem`, `Path`, `effect/cli`, `effect/process`) has to be listed in `allowedUnstableApis` in the root `tsconfig.json`.

| Native                                                     | Effect                                                                                                                                                                                                       |
| ---------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Top-level `await`, `process.exit`, `process.exitCode`      | `NodeRuntime.runMain` over the program with `Effect.provide(NodeServices.layer)`; fail with a tagged error for a non-zero exit                                                                               |
| `node:fs`, `node:fs/promises`                              | `FileSystem.FileSystem`: `readFileString`, `writeFileString`, `readDirectory`, `makeDirectory`, `exists`, `realPath`, `remove`                                                                               |
| `node:path`, `fileURLToPath` from `node:url`               | `Path.Path`: `join`, `resolve`, `dirname`, `relative`, `fromFileUrl(new URL("../", import.meta.url))`                                                                                                        |
| `execFile`, `spawn`, `spawnSync` from `node:child_process` | `ChildProcess.make(command, args, { cwd })` from `effect/process`, run through `ChildProcessSpawner`: `string`, `lines`, `exitCode`, or `spawn` for a streaming handle; `ChildProcess.pipeTo` for a pipeline |
| Reading `process.argv`                                     | `Command.make` with `Flag.String`, `Flag.Boolean`, and `Argument.String` from `effect/cli`, then `Command.run`                                                                                               |
| `JSON.parse` of a file or a command's output               | `Schema.decodeUnknownEffect(Schema.fromJsonString(schema))`                                                                                                                                                  |
| `console.log` of a result, `process.stdout.write`          | `Console.log`; diagnostics through `Effect.log*` with `Logger.layer([Logger.withConsoleError(Logger.formatLogFmt)])` (logfmt on stderr)                                                                      |
| `setTimeout` to poll                                       | `Effect.sleep`, `Effect.repeat` with a `Schedule`                                                                                                                                                            |
